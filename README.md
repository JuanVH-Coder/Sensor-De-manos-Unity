# Sensor de manos Unity

Proyecto de Unity para seguimiento de manos con Ultraleap / Leap Motion.

## Tecnologias

- Unity 2022.3.54f1
- Ultraleap Tracking 7.2.0
- TextMesh Pro

## Contenido del repositorio

Este repositorio incluye las carpetas principales del proyecto:

- `Assets`
- `Packages`
- `ProjectSettings`
- `.vscode`
- `Library`

`Library` se conserva en este repositorio para mantener una copia completa del estado del proyecto en la maquina donde fue preparado. Ten en cuenta que esto hace que el repositorio sea pesado.

## Como abrir el proyecto

1. Abre Unity Hub.
2. Agrega la carpeta del repositorio como proyecto local.
3. Usa Unity `2022.3.54f1`.
4. Abre la escena `Assets/Scenes/SampleScene.unity`.

## Dependencias principales

- `com.ultraleap.tracking`
- `com.unity.textmeshpro`
- `com.unity.visualscripting`
